## Meditation 예산

Meditation 조건의 전체 비용에는 Remember, Dream, 임베딩, Recall, 답변, 채점도 포함된다. **주간 Meditation 실행 자체는 0.15398834달러**, API 호출 9회였다. 실행당 상한 5달러의 약 3.08%를 쓰고 작업을 마쳤다. 남은 예산을 채우려는 추가 실행은 없었다.

이 주간 실행은 depth 1 기억 2개를 추가했다. 나머지 depth 1 기억 7개는 앞선 Dream에서 생성됐다. 최종 양의 관계는 5개, 음의 관계는 0개였다. 다른 조건에서는 관계가 생성되지 않았다.

## 검토한 내용

- 모든 저장 그래프의 기하급수 root 제약·부모 깊이·provenance 검사 통과. 제안 거절과 cutoff 이후 기억은 없었다.
- 각 추상 기억의 Source root는 여러 개지만 모두 원래 세션 하나에서 왔다. root를 여러 독립 대화로 해석할 수 없다.
- Dream의 depth 1 기억 여러 개는 같은 용어 구분을 조금씩 다른 문장으로 반복했다. 문자열이 완전히 같은 추상 기억 수는 0이므로 문자열 일치 지표만으로 의미 중복을 측정할 수 없었다.
- Meditation이 추가한 두 기억은 기존 내용에서 표현 차이와 용어 간 경계의 불명확함을 더 구체적으로 기술했다. 이 작은 사례만으로 일반적인 개선 효과를 주장하지 않는다.
- 검토한 추상 내용은 대화 속 설명을 특정 사람의 상태나 진단으로 확대하지 않았다. 이 관찰 역시 한 문항의 정성 검토에 한정된다.
- 동일 입력이어도 Remember 생성 결과가 6개 또는 7개였다. 조건별 독립 LLM 실행의 변동을 확인했다.
- 다섯 조건 모두 같은 답을 맞혔으므로 이 문항에서는 Dream/Meditation의 정확도 이득이 관찰되지 않았다.

## 검증과 재현

전체 자동 테스트 212개가 통과했다. 가짜 HTTP와 실제 SQLite를 이용해 데이터 분리, 미래 정보 차단, 날짜 경계 재개, 기하급수 제약, 주간/전체 예산 구분, 미정산 예약, 공통 완료 문항 집계를 검증했다.

실제 파일럿 완료 뒤 같은 실행 명령을 다시 실행했다. API 호출 수 185회, 실제 비용 0.47084921달러가 그대로 유지됐고 답변/채점의 추가 호출은 없었다.

로컬 결과는 TestResults/benchmark-pilot에 보존했다. manifest.json은 설정을, report.json과 analysis.json은 비용·판정을, 각 조건의 corpus/graph.json/evidence.json은 원문과 근거를 담는다. API 키와 원본 데이터/실험 저장소는 Git에 포함하지 않았다.

실행 조건과 제약은 [Benchmark 설계와 실행](10-benchmark.md)을 따른다. oracle 입력과 내부 채점의 특성 때문에 이 수치를 공식 LongMemEval S 점수와 비교하지 않는다.

실행에 사용한 바이너리는 같은 폴더의 runtime에 보존했다. 구현 바이너리가 달라지면 재개 fingerprint 검사가 거부하므로, 원래 실행을 재개할 때는 이 runtime을 사용한다. 새로운 빌드는 새 실험 폴더에서 실행한다.
